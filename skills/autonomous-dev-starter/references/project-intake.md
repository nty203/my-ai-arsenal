# Project Intake

`autonomous-dev-starter`는 프로젝트 유형을 미리 가정하지 않는다.
사용자의 현재 요청에 충분한 정보가 없을 때만 아래 질문을 한 번에 묶어서 묻는다.

## 최소 질문

1. 무엇을 만들고 싶은가? 한두 문장으로 목적과 사용자를 설명한다.
2. 새 프로젝트인가, 기존 프로젝트를 이어서 개발하는가? 기존이면 대상 폴더를 지정한다.
3. 결과물 유형은 무엇에 가장 가까운가? 웹/모바일·데스크톱 앱/API·백엔드/게임/자동화·봇/CLI/데이터·AI/문서·콘텐츠/기타.
4. 첫 번째로 반드시 동작해야 하는 핵심 기능 또는 완료 조건은 무엇인가?
5. 실행 방식 선호가 있는가? ChatGPT Remote / Local CLI / 자동 선택.

사용자가 이미 답한 항목은 다시 묻지 않는다. 3~5개보다 적은 질문으로 충분하면 줄인다.
